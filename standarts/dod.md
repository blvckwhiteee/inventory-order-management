# Definition of Done (DoD)

Кожна задача вважається виконаною лише тоді, коли відповідає наступним критеріям:
1. **Код написаний та працює** згідно зі специфікацією (`spec.md`).
2. **Git-hooks пройдені:** лінтер не видає помилок, форматування відповідає Prettier.
3. **Smoke-тест та збірка (`npm run build`)** проходять успішно.
4. **Залежності обґрунтовані:** не додано зайвих npm-пакетів без нагальної потреби.
5. **Архітектурні зміни задокументовані:** якщо змінено структуру БД або API, написано/оновлено ADR.
