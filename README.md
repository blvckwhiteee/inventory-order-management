# Inventory & Order Management API
Це бекенд-сервіс для управління складськими запасами та обробки замовлень. Створений з фокусом на строгі інженерні стандарти, модульну архітектуру та консистентність даних.

## Мета проєкту
Забезпечити надійний процес створення замовлень із гарантованим резервуванням товарів на складі, уникаючи проблеми "race conditions".

## Технологічний стек
- **Runtime:** Node.js
- **Мова:** TypeScript
- **Фреймворк:** Fastify
- **База даних:** PostgreSQL + Prisma ORM
- **Тулінг:** ESLint, Prettier, Husky, lint-staged
- **Тестування:** Jest

## Структура стандартів проєкту
Всі архітектурні рішення, формат специфікацій та критерії готовності (Definition of Done) знаходяться у директорії `/standards`.
